# Tic-Tac-Toe Gaming Application

A simple browser-based Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Features

- 3x3 game board
- Two-player turn-based gameplay
- Win detection and draw state
- Board reset button
- Responsive UI for desktop and mobile

## Getting Started

Open `index.html` in a browser, or run a local server from the project root:

```bash
npm start
```

Then open `http://localhost:8080` in your browser.

## Project Files

- `index.html` — game interface and structure
- `style.css` — visual styling
- `app.js` — game logic
- `package.json` — project metadata and start script

## Additional Projects

- `task-manager/` — Java + Angular task manager / to-do application

## How to Play

1. Click an empty cell to place `X` or `O`.
2. Players alternate turns.
3. The first player to line up three marks horizontally, vertically, or diagonally wins.
4. If the board fills with no winner, the game ends in a draw.

Enjoy the game!
